# Henry Oyoto — Personal Portfolio

Static GitHub Pages portfolio for Henry Oyoto.

## DIELCHA alignment

The Projects section now uses the same selected project names and cover imagery presented on DIELCHA DIGILAB. The project source links are kept under the personal `HenryOyoto` GitHub account, while DIELCHA remains the engineering-studio presentation of the work.

The site is intentionally static: HTML, CSS, JavaScript and local assets only. No build step or server is required.

## GitHub Pages

Upload/commit the contents of this repository to `HenryOyoto/HenryOyoto.github.io`. Relative asset paths are preserved for GitHub Pages.


## Replacing the hero placeholder images

Two distinct, named placeholder images are used for the hero sections:

- `assets/images/hero-home-embedded-systems.svg` — homepage hero background.
- `assets/images/hero-projects-engineering-work.svg` — projects-page hero background.

Replace the contents of each file while keeping its filename and SVG format, or update the matching `src` in `index.html` / `projects.html` if using JPG or PNG. The freelance platform logos are `assets/icons/upwork-logo.png` and `assets/icons/fiverr-logo.png`. Their links temporarily point to the GitHub profile until real profile URLs are available.
